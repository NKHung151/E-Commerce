# E-Commerce Frontend

Minimal React frontend for the E-Commerce microservices platform.

Quick start:

1. Install dependencies

```bash
cd frontend
npm install
```

2. Run

```bash
npm start
```

This frontend proxies API requests to `http://localhost:8080` by default.

Notes:
- The UI is a light scaffold; you can connect more features and style with Tailwind.
- Ensure backend services are running (API Gateway on port 8080).
